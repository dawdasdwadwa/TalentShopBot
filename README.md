# Talent Shop Bot

Discord бот для автоматизации магазина с ИИ-конвейером на Groq.

## Функции

- 🛒 Магазин с категориями и товарами
- 🎫 Система тикетов для заказов
- 🤖 ИИ-конвейер с 7 режимами
- 📊 Статистика и аналитика
- ⭐ Отзывы и рейтинг продавцов

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения.

## Запуск на Railway

1. Подключите репозиторий
2. Добавьте переменные
3. Деплой

## Технологии

- Python 3.13
- discord.py
- SQLite
- Groq API
